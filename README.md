# Moksh Rijhwani — Football Anime Portfolio

A zero-build static portfolio inspired by the approved football/anime concept. It uses plain HTML, CSS and JavaScript, so you do not need Node.js to run it locally.

## Run locally
Open `index.html` in a browser.

For the smoothest local preview, use VS Code + Live Server, or any simple static server.

## Deploy to Vercel
### Option A — easiest
1. Put this folder in a ZIP and extract it.
2. Go to Vercel and sign in.
3. Choose **Add New → Project**.
4. Import the folder/repository, or use Vercel's drag-and-drop deployment if available.
5. No build command is required.
6. Deploy.
7. Vercel gives you a `.vercel.app` URL.

### Option B — GitHub
1. Create a GitHub repository.
2. Upload every file in this folder.
3. In Vercel choose **Add New → Project → Import Git Repository**.
4. Select the repository.
5. Framework preset: **Other**.
6. Build command: leave empty.
7. Output directory: leave empty / root.
8. Deploy.

## Important
- Phone number is intentionally hidden.
- The CV PDF is included under `assets/`.
- Replace `assets/anime-hero.png` if you later want a different anime portrait.
- Update the email/LinkedIn in `index.html` if needed.
- The website is static and can be moved to Netlify, GitHub Pages or other static hosting too.


## What was added in the cinematic version
- Full-screen cinematic loading sequence
- Animated stadium light sweep
- Hero parallax on scroll
- Interactive 3D tilt on cards
- Animated football-themed pitch/playbook
- Floating particles
- Scroll progress bar
- Micro-animations throughout the sections
- Reduced-motion fallback for accessibility

## Important note
This is intentionally a static site (HTML/CSS/JS), which keeps deployment simple and cheap. You can later migrate it to Next.js/React if you want a CMS, analytics dashboard, blog, password-protected recruiter area, or more advanced 3D scenes.
